# Maryam Allahkhani — Personal Homepage

A responsive personal portfolio built with plain HTML, CSS, and a small amount of JavaScript. It is intended for GitHub Pages and does not require a build step or package installation.

## Files

- `index.html` — content and page structure
- `style.css` — layout, typography, colors, and responsive styles
- `script.js` — mobile navigation and automatic footer year

## Run locally

Open `index.html` in a browser. The page uses DM Sans and DM Serif Display from Google Fonts; system fallbacks are included.

## Projects and links

All 18 projects from the résumé's project sections are included and grouped by field. Links are provided only where a project repository or project website was linked in the résumé. Internal R&D and company projects are identified as such rather than being presented as public repositories.

## Certificates

All seven certificates are listed. Each card links to the corresponding certificate image URL extracted from the résumé. A second link opens the issuing platform or credential page where the résumé provides one.

## Languages

English and French are included with the five-point indicators represented in the résumé (English 4/5; French 2/5). These are visual indicators, not CEFR classifications.

## Publish with GitHub Pages

1. Create a public repository named `m-allahkhani.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Select **Deploy from a branch**, then select `main` and `/ (root)`.
5. Save and visit `https://m-allahkhani.github.io` after deployment completes.

## Before publishing

Open every certificate link once from your own browser to confirm that the issuing websites remain accessible. External certificate image links are retained as supplied in the résumé; no certificate image has been fabricated or altered.
